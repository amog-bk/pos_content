# Note about this sample week

The two files in this folder (`digest.md` and `partner-messages.md`) are a
**hand-crafted preview** of what the scraper would produce for an average
week. They were generated by hand because the sandbox where the framework was
written has outbound network access blocked to the listed sources (every
domain returns HTTP 403).

The **real Week-1 run** will happen when:

1. This branch is merged, OR
2. You go to **Actions → Weekly insurance roundup → Run workflow** and
   trigger it manually. GitHub Actions runners can reach the sources.

The format and voice you see here are exactly what the scraper produces — only
the items are illustrative.

Items shown below are plausible based on the source map and what these
publications typically cover. Verify against the live links before sending
anything to Partners.
